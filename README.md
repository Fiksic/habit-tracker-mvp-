# Habit Tracker MVP

Мотивирующий трекер полезных привычек для удержания фокуса, отметки ежедневного выполнения и отслеживания серий успехов («стриков»).

## Цель проекта

Создать минимально жизнеспособный продукт (MVP), который помогает пользователю:
- создавать и управлять привычками;
- отмечать выполнение и оставлять заметки;
- отслеживать метрики (стрики, процент успешности);
- получать напоминания;
- сохранять и загружать данные.

## Функциональные модули

1. **Менеджер привычек (Habit Manager Module)** — создание, редактирование, архивация и удаление привычек.
2. **Журнал отметок и Календарь (Check‑in Module)** — фиксация статуса выполнения и добавление заметок.
3. **Модуль метрик и Стриков (Streak & Gamification Module)** — расчёт текущего и лучшего стрика, процента успешности.
4. **Система напоминаний и Хранение (Notification & Storage Module)** — управление напоминаниями, сохранение и загрузка данных.

## Технологии

- Язык: Python 3.8+
- Хранение данных: JSON (по умолчанию) или SQLite (опционально)
- Тестирование: pytest
